# Security policy

This repository accepts only synthetic event, ad, campaign, dimension, window, aggregate, and failure fixtures. Do not report or
attach real credentials, tracking identifiers, advertiser/campaign/user/device data, clickstream, pricing, billing, fraud signals,
production topology, storage paths, or internal analytics metadata.

For a suspected repository vulnerability, open a GitHub security advisory when a public remote exists. Public issues are suitable
only for non-sensitive correctness bugs. This laboratory is not a deployed analytics, advertising, fraud, attribution, or billing
system.
