# Repository instructions

- This is an independent clean-room learning repository for one bounded ad-click aggregation invariant.
- Keep client emission, gateway acceptance, durable event identity, aggregate contribution, window publication, query receipt,
  fraud review, billing decision, charge, advertiser report, and external acceptance as separate facts.
- Never add real credentials, advertiser/campaign/user/device identities, tracking URLs, clickstream, pricing, invoices, internal
  topology, copied third-party prose, diagrams, images, tables, data, benchmarks, or code.
- Preserve unrelated work. Stage exact paths, keep commits single-purpose, and do not add co-author trailers unless requested.
- Infrastructure-dependent conclusions require the matching real service or true process boundary in public CI; mocks cannot prove
  durable deduplication, window finalization, replay, checkpoint fencing, or correction recovery.
- A benchmark is a bounded synthetic observation for its exact fixture and runtime, never traffic, revenue, billing, fraud, SLA,
  or production-capacity evidence.
